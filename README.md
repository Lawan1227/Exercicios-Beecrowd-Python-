## 🎯 Objetivos

- Praticar lógica de programação e pensamento computacional.
- Desenvolver habilidades com a linguagem Python.
- Aprimorar a resolução de problemas algorítmicos.
- Registrar minha evolução por meio de exercícios práticos.

## 📚 Conteúdos praticados

- Entrada e saída de dados
- Variáveis e operadores
- Estruturas condicionais
- Estruturas de repetição
- Strings e listas
- Funções e outros fundamentos de Python

*Os conteúdos serão ampliados conforme meu progresso nos estudos.*

## ▶️ Como executar

Com o Python instalado, abra o terminal na pasta do exercício e execute:

```bash
python 1001.py
```

Substitua `1001.py` pelo nome do arquivo que deseja executar.
